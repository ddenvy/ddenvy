## 🧪 About Me

I'm a **Scientific Software Engineer** with 5+ years of experience building software for laboratory systems, scientific instrumentation, and AI-integrated research platforms. My background spans **.NET backend development**, **chromatography data systems**, and **LLM-powered lab tools** — with a strong focus on data integrity, regulatory compliance (21 CFR Part 11 / ALCOA+), and production reliability.

I transitioned from lab work to software engineering, which gives me a unique perspective — I understand both the science and the code behind scientific software.
